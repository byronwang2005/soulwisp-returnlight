# 《亡絮：归灯》Soulwisp: Returnlight · 四人制作与成长规则

2026-10-10 · 运行规则 wangxu-0.1.0 · 四人优先；本地完成并逐档验收4–10人后统一上云。

探索、轻量战斗、证据议会、祝福构筑、护送与营地养成形成一局。免费 KayKit GLB 直接实时渲染，React / R3F 固定正交镜头显示三维，服务端按二维地图裁定。数值以 [运行配置](../packages/rules/src/config.ts) 和 [动作内容](../packages/rules/src/content.ts) 为准。

## 一局结构

| 项目 | 四人当前值 |
| --- | --- |
| 阵营 | 3守灯者 / 1蚀月者；公开职业与形态选定后随机身份 |
| 职业 | 灯卫、斥候、拾荒者、行商各一席，各两互斥形态 |
| 地图 | 归灯堂与四处外环地标，5节点、3布局变体 |
| 阶段 | 准备45秒；三章各探索150 / 议会60 / 投票20 / 祝福15秒；撤离90秒 |
| 常规时长 | 14分30秒，网络异常等待可能延长 |
| 目标 | 2灯柱、守门精英、归灯芯净化与最后8秒护送 |
| 工程 | 保底12份亡絮分章释放；每灯柱2、净化2、每次降蚀2 |
| 蚀月 | 终局必须<5；每章最多降蚀一次 |
| 狼预算 | 每章2蚀息；腐化4秒、升月1、共享冷却20秒、打断重试10秒 |
| 腐化限额 | 每祭坛每章一次，狼队每章最多两次；撤离沿用第三章剩余额度 |
| 永久离场 | 首章仅监视；全局最多封印一人；四人无狼人永久终结 |

全员能贡献、救援、交换，职业不认证阵营。普通攻击 / 推挤、闪避、交互与一个职业技能组成轻量操作。倒地可救，20秒后回归；携带物落地可回收。归灯芯只有一个实例，通过自愿交接、主动丢下或倒地掉落转移。

工程亡絮只用于本局；每章结束未交付 / 未拾取的保底工程份额归公共仓库，私人珍藏与遗物保持归属。章内扣料可以施压，跨章不能永久扣住保底工程。

## 议会、票决与回响

议会暂停地图行动与技能。四人按席各10秒发言，余20秒自由讨论。内置语音只开议会，权限由服务器管理；文字与证据同样可用。

投票开始冻结资格：活人加未用遗票回响。严格超过分母一半才通过；弃权不降低分母。回响投票或主动弃权消费一次遗票，未参与保留。首章通过仅给下一章有限监视；第二章起可封印，全局最多一人；额度用尽后仅20秒禁锢。

被封印者成为回响：保留生前信息、每章80字短消息、一次遗票与阵营奖励，不增探索视野，也不能发麦。封印不揭身份，正确封狼仍等固定终钟。系统 / 观察 / 玩家陈述有来源类型；斥候报告保留原事件ID，不能把同一事件包装成多份独立认证。

## 终局

90秒撤离中，前82秒完成目标与护送；仅最后8秒产生有效守圈。归灯芯连续在撤离圈，同时至少一名未封印、未倒地人类本人连续参与8秒。离圈重置个人资格，芯离圈重置公共进度，换人接力不能代替同一人连续参与。

最后tick同时检查灯柱、精英、芯净化、当时蚀月<5、芯守圈和人类连续资格。公共界面只显示芯的位置与公共进度，不显示参与者是否人类。全部狼人被封印也在终钟判人类赢；其他情况狼赢，没有人数持平立即胜利。

暴露狼可夺芯、击倒、推挤、放雾、守祭坛或腐化；人类可防守读条、回收、救援与降蚀。错封后两人类一狼继续走完整目标路线。

## 职业、构筑与能力成长

| 职业 | 形态0 | 形态1 |
| --- | --- | --- |
| 灯卫 | 近处单人55点移动盾 | 定点每人一次25点薄盾；5秒、18秒冷却 |
| 斥候 | 当前区近20秒痕迹，按15秒粗化 | 当前及相邻区近45秒痕迹，按30秒粗化；无姓名 |
| 拾荒者 | 3秒，一批最多两份储藏内容 | 2秒，分批一份；第一份更早可用 |
| 行商 | 双方确认当面交付，未确认10秒过期 | 双方确认锁物3秒托管交付，未确认30秒过期；失效释放锁 |

每章议会后从三张祝福选一，超时选第一张；八祝福与四遗物支持移动、护盾、救援、工程、观察、搬运等构筑。局内遗物数值不继承下一局。

永久研究保存第二技能形态的收藏和配装，并赠职业银絮配色。**标准局全部账户都可免费选两形态**：能力养成可实装，新老玩家同一起点。没有永久生命 / 伤害 / 倍率 / 票权或额外技能栏优势。

## 结算与营地

当前持久内容是残片、秘文、外观、研究、摆件、当前配装、最多五套账户配装预设、教程、场次与胜场。预设组合名称、外观、职业与技能形态，刷新或更换设备后仍可读取。熟练度故事、交易市场和扩大收藏目录留待后续内容版本。

| 结果 | 残片 | 秘文 |
| --- | --- | --- |
| 有效局阵营胜利 | 10+20+min(10,寄存+携带价值)，最多40 | 2 |
| 有效局阵营失败 | 10+floor(min(10,寄存价值)×0.25)，最多12 | 1 |
| 封印 / 回响 | 同阵营规则，保留基础与胜利奖励 | 同阵营规则 |
| 长断线 / 语音关房失败无效 | 不新增材料、场次、胜场；原库存保留 | 0 |

狼胜不要求到人类撤离圈，也不要求帮助人类工程。胜利至少30，失败藏物最多12。一次寄存最多两件；失败只回收寄存部分，反复交接不生成新物品。

## 0元素材与实时三维

主资源为 [KayKit Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0) 与 [Dungeon Remastered](https://github.com/KayKit-Game-Assets/KayKit-Dungeon-Remastered-1.0) 免费CC0部分，角色含骨骼动画。直接加载GLB，后续换装、材质、附件和新模型继续同一接口。采购支出0元，来源、commit、动画和SHA-256见 [资源清单](../apps/web/public/assets/manifest.json)。

React DOM负责房间、训练、HUD、证据和工坊；R3F Canvas负责人物、地形、装置与危险范围。演出集中于灯柱、净化、月变、封印和最后八秒，手机限制阴影与粒子。Phaser离线转精灵、PVGames付费主包不再是本轮路线。

## 完整开发顺序

1. 四人先完成训练、真实房间、全部胜负路径、营地与议会语音。
2. 四人真实浏览器与真人验证误封、抱团 / 分路、物资争夺、重连与秘密载荷。
3. 依序完成并验收5、6、7、8、9、10人职业、地图、预算和完整阶段，再轮换身份真人试玩。
4. 本地十人一房完整一局并接议会音频，记录实际机器与网络表现。
5. 全档本地通过后迁移一台VPS，验收HTTPS/WSS、UDP/TURN、备份恢复与公网流程；Pages可选。

自动化验证规则、权限与事务；策略胜率和社会推理乐趣需要真人校准。实际完成情况见 [开发状态](development-status.md)，运行边界见 [架构](architecture.md)。
