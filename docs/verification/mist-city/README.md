# 灰雾旧城与渲染稳定性验收

实现位于 `feat/mist-city-stability`。保留服务器移动、职业与技能形态、声音和大厅接口；新增协议字段均可选。旧服务器缺少 `self.visibility` 时关闭探索迷雾，角色仍按授权坐标过滤。

## 视觉与权限

- 十一类区域使用合批石基、铜件、旧木和粗布造型；后侧边缘为高轮廓，区域平台、道路和全部章节设施位置均经过静态占地核对。
- 归灯门的名称和主题交换到实际撤离点所在节点，不改 ID、半径、坐标或连接。
- 移除旧纯色方柱，外围继续实例化现有 KayKit 柱体并使用砌石贴图。墙柱 UV 从原调色板图集重新按几何表面投影，避免新贴图只采样极小色块。
- 地基下方是低频灰雾与土石色过渡，后方是分层屋脊、断墙及铜架剪影；全图旋转白点替换为灯柱旁的少量银白纤维。减少动态时停止纤维舒展。
- 服务端复用原来的视距计算，显示回望 +15%、旧巡灯 +10%。灰雾圆与视距圆以 128 边凸多边形裁剪，只传交集边界，不传视野外中心或施放者。
- 当前视野、已探索地形、未探索地形分别为清晰、暗淡轮廓、浓雾。探索缓存只有 256×256 地形格，限定当前对局与自身 ID；断线重连保留，刷新或新对局清空。封印不新增记录，议会及结果停用迷雾。
- 公开设施在小地图与导航保留标记，三维动态设施只呈现当前可见范围内的状态。最新授权视图中坐标为 null 的角色立即从渲染列表移除。

## 卡顿排查改动

纹理由画布级 provider 集中加载和初始化，每张纹理只配置一次，每个 renderer 只显式初始化一次。材质由消费组件持有并统一在 hook 中释放；常规进度、位置和透明度更新不重建骨架、附件、地基或区域几何。手动画质切换可以保留 Three.js 加载缓存。

自动画质从均衡级开始，所有运行级别固定 1K 色图、512 ARM 与法线；只调整 DPR、阴影和装饰密度。手动高画质仍使用 2K 地面色图，手动最低画质不请求法线。

距离场与路径求解在原生模块 Worker 中完成。目标、布局或授权障碍变化才重建距离场；位置更新复用距离场。双序号过滤过期回复；重建期间隐藏旧路线，目的地标记保留。

## 预算与离线图

`budget.json` 覆盖 4–10 人 × 三种布局：新增区域和远景为 7 个材质批次，背景与银絮共 2 个批次，合计 9。最多 3,568 个三角面；银絮是线段，不计三角面。已有地基、角色、设施及外围实例批次不属于新增预算。

迷雾遮罩 RGBA8 为 256 KiB，无额外噪声纹理。全七类贴图冷加载含 mip 链估算：自动约 56 MiB，高画质约 144 MiB，另加遮罩。数值不包含模型自带图、阴影、环境贴图、驱动开销或手动切换保留的缓存。

## 已执行验证

Node.js 24.21.0；使用 `npm ci` 和提交锁文件。

- `npm run check`：类型检查。
- `npm run build`：前端、导航 Worker 和服务端生产构建。
- `npm run assets:check`：10 个运行模型、37 张纹理哈希与许可，以及依赖许可清单。
- 250 项指定静态测试（11 个文件）：迷雾、区域、地基、导航、交互、规则、移动脚步、攻击声音、音乐、大厅协调与等待房间。
- CPU 离线预览已生成并人工查看区域、柱体及迷雾图。没有浏览器、联机或 GPU 采样；实际帧耗时和游戏内光照尚未实测。

远端兼容基线：`origin/main` 的 `b2267c8`，包含 `3391b86` 自动大厅、`28ce629` 首页入口、`9496ed4` 等待控制及其测试修正。整合后重新通过上述检查；功能分支本轮只推送，不合入 main。
