## 实现

首页隐藏整个配装工坊，保留账户概况、营地预览、远征与训练入口，营地固定播放营地音乐。已保存的配装仍用于预览及房间默认选择；服务端收藏、制作、研究和预设接口保持原逻辑，无数据库迁移。房间继续支持九种职业、技能形态及十人重复灯卫。

职业通过可见部件、局部颜色和原骨骼附件区分，身体尺度不变；法师尖帽在行商、药师、验痕师上隐藏。斥候保留罩帽、巡林客使用无罩帽原模型；附件包含肩灯、货包、药袋、护目镜、齿轮护臂、卷宗、铜钟及箭袋。守卫保留独立暗铜色、红盔饰和 Blocking 戒备动作。

设施在原服务端位置与占地内构建，并按材质合批。灯柱为石座铜框灯笼，祭坛为破损石台铜架，降蚀台为铜绿容器，净化台为六边灯芯托架，撤离门保留开口。发光反馈按授权进度驱动。

广场2.7、道路3.3单位每次平铺，较原来放大1.5倍；世界坐标低频明暗与铜绿、合批稀疏裂纹和苔藓降低重复感。整体并集的外边界和孔洞向下延伸0.6单位，内部连接不生成墙；背景为-0.72。完整墙、断墙、柱体与低矮石岸避开通行区域。

## 静态证据

- `npm run check`：Node.js 24 类型检查。
- `npm run build`：前端与服务端生产构建；前端仍有现有大包提示。
- `npm run assets:check`：10个运行 GLB、37张 WebP、原始来源哈希、输出尺寸、CC0许可、身体2.2单位/脚底0、守卫动作及运行依赖许可。
- `npx vitest run tests/art-assets.test.ts tests/scene-interaction.test.ts`：65项通过，包括4–10人 × 三种布局的21个边界组合，侧壁有限坐标、厚度、法线、孔洞和连接，设施占地、附件骨骼、41个关节、保留动作及最低档加载路径。
- `npm run art:preview`：离线 CPU 投影与2×2纹理平铺图，未使用浏览器或 WebGL。

[模型统计](art-models.json)记录每文件裁剪前后字节、三角面数和动画。10个实际使用模型从17.59 MiB缩至3.21 MiB；每个人物由76个动画裁剪为10个，裁剪不改变身体几何。原始模型和生成源 PNG 位于非发布目录。

[纹理统计](art-assets.json)记录档位与内存估算。全部七类材质冷缓存 RGBA8、完整 mip 链估算：最低档约46.67 MiB、均衡低档约56 MiB、高档144 MiB。最低档请求14张颜色/ARM图、零张法线；高档地面颜色2K、数据1K，其余材质不超过1K。质量切换缓存可能保留额外贴图，以上不是设备 GPU 实测。

生成源图实际为1254×1254，2K地面颜色为重采样输出。遮罩派生法线与 ARM 不代表扫描级 PBR。KTX2留待后续。
