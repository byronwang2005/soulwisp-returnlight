# 古铜与古籍视觉系统

全局采用古铜铭牌、氧化铜绿、羊皮纸与炭黑的中世纪搭配，覆盖营地、房间、故事教程、议会、探索、结算、设置及三维石城。铜色材质方向参考[PANTONE 876 C](https://www.pantone.com/color-finder/876-c)；以下为屏幕阅读调校后的sRGB设计值。

| 用途 | 颜色 | 设计值 |
| --- | --- | --- |
| 页面底色 | 炭黑 | `#171512` |
| 面板 | 古城暗绿 | `#25251e` |
| 铭牌与边框 | 古铜 | `#b58a58` |
| 高亮与选中 | 抛光铜光 | `#dfbc87` |
| 正文 | 羊皮纸 | `#efe4ce` |
| 次级文字 | 旧纸灰 | `#aaa794` |
| 正向状态 | 氧化铜绿 | `#9ab7a5` |
| 危险与蚀月提示 | 暗红高亮 | `#e6978e` |

三维背景、雾、石材和灯光沿同一暖铜／暗绿方向调整。资源、危险和职业颜色继续保持区分；所有场景尺寸、服务端碰撞和技能规则保持原配置。

## 开源中英文配对

标题、品牌和故事采用**Noto Serif SC／思源宋体 × Source Serif 4**；操作正文、按钮、表单与数字采用**Noto Sans SC／思源黑体 × Source Sans 3**。英文族放在字体栈前方，中文使用对应的思源字形。宋体的古典书卷结构与铜质界面相配，操作区域的黑体保持快速阅读。

选择依据：[Source Serif](https://github.com/adobe-fonts/source-serif)由Adobe开源并明确为Source Sans设计；[Source Sans](https://github.com/adobe-fonts/source-sans)面向用户界面；[思源宋体](https://github.com/adobe-fonts/source-han-serif)提供中日韩字形。中英文配对是本项目根据衬线结构、视觉字重与功能层级做出的设计选择。

| 层级 | 中英文配对 | 字重／间距 |
| --- | --- | --- |
| 主标题与品牌 | 思源宋体／Source Serif 4 | 600，字距0.025–0.035em |
| 剧情与引文 | 思源宋体／Source Serif 4 | 400–500，宽松行距 |
| 操作正文与按钮 | 思源黑体／Source Sans 3 | 正文400，按钮600 |
| 倒计时与数值 | 思源黑体／Source Sans 3 | 等宽数字 |

字体均为OFL-1.1，经锁定版本Fontsource包自托管，按Unicode范围加载；不再发布马善政毛笔体。Source Serif启用光学字号适配，数字采用等宽排版。采购成本0元，完整声明随[第三方许可](../apps/web/public/THIRD_PARTY_NOTICES.txt)发布。

## SVG意义与状态规则

所有按钮逐一配置`iconKind`和业务状态，复用CCC的morphicons与lucide。图标不再根据中文标签推断，也不根据悬停或选中猜测操作是否成功。

| 按钮层级或功能 | 未触发 | 交互／状态变化 |
| --- | --- | --- |
| 集市／大厅／训练、工坊标签 | 对应功能图标 | 选中保留图形，仅铜色背景、边框和文字高亮 |
| 职业／形态／人数／投票目标 | 对应职业或功能图标 | 保持同族图形，通过框和选中状态区分 |
| 普通操作与方向键 | 固定功能图标 | 悬停或聚焦仅轻微上移1px，方向和含义不变 |
| 麦克风、收听、音乐 | 开启图形 | 实际关闭时显示关闭图形 |
| 展开收起 | 下箭头 | 实际展开后上箭头 |
| 复制、准备、提交 | 原功能图标 | 请求或服务端状态确认后才显示完成勾 |
| 网络请求 | 原功能图标 | 实际处理中显示加载环，结束恢复 |

相同层级采用相同交互规则。导航通过`aria-current`标注当前页，职业和投票通过`aria-pressed`标注选择；SVG为读屏隐藏装饰，操作含义由文字与状态表达。

顶部旧下划线伪元素被删除：它原本是块元素，在按钮采用横向排列后成了额外flex子项。顶部和工坊导航现在统一使用按钮内部选中框，不产生向外延长的线。减少动态设置会关闭位移和变形动画；忙碌状态旋转也遵循该设置。

主要正文与炭黑底的对比度超过7:1；主按钮最暗铜色与深色文字约5.98:1，次级文字与较亮面板约5.43:1。实际浏览器检查字体加载、SVG变形、键盘聚焦、减少动态设置和移动布局，记录见[视觉验收](verification/bronze-design.json)。
