# 古铜与古籍视觉系统

全局采用古铜铭牌、氧化铜绿、羊皮纸与炭黑的中世纪搭配，覆盖营地、房间、故事教程、议会、探索、结算、设置及三维石城。铜色材质方向参考[PANTONE 876 C](https://www.pantone.com/color-finder/876-c)；以下为屏幕阅读调校后的sRGB设计值。

| 用途 | 颜色 | 设计值 |
| --- | --- | --- |
| 页面底色 | 炭黑 | `#171512` |
| 面板 | 古城暗绿 | `#25251e` |
| 铭牌与边框 | 古铜 | `#b58a58` |
| 高亮与选中 | 抛光铜光 | `#dfbc87` |
| 正文 | 羊皮纸 | `#efe4ce` |
| 次级文字 | 旧纸灰 | `#aaa794` |
| 正向状态 | 氧化铜绿 | `#9ab7a5` |
| 危险与蚀月提示 | 暗红高亮 | `#e6978e` |

三维背景、雾、石材和灯光沿同一暖铜／暗绿方向调整。资源、危险和职业颜色继续保持区分；所有场景尺寸、服务端碰撞和技能规则保持原配置。

## 古体字体

- **马善政毛笔楷体**用于游戏名、主标题、章节名和祝福名称，形成古籍题签的书法感。[字体与OFL许可](https://fontsource.org/fonts/ma-shan-zheng/about)
- **Noto Serif SC／思源宋体**用于正文、对白、按钮、输入框与三维铭牌，保留古典结构及清晰笔画。
- **Noto Sans SC／思源黑体**用于倒计时、血量、货币数字、快捷键、英文标识与网络诊断。读数采用等宽数字，避免数值更新时抖动。

三套字体均随生产静态资源自托管，使用Unicode范围分片按需加载，无外部字体服务依赖。字体采购成本0元；完整OFL声明随[第三方许可](../apps/web/public/THIRD_PARTY_NOTICES.txt)发布。字库尚未加载时显示系统字体，加载后重绘三维铭牌。

## 按钮与SVG

全部页面按钮通过统一的`ActionButton`绘制SVG，复用CCC-Attendance的**morphicons 1.7.1 + lucide 1.26.0**。文字和可访问名称仍用于解释操作，SVG为装饰元素，不额外进入读屏名称。

悬停、键盘聚焦与按下触发相应图形变形；准备、选中、复制成功、已收藏和等待状态展示不同图形。方向键在变形时保留方向含义，触屏输入保留指针捕获和松开停止行为。无交互时图标静止，无持续装饰动画；系统或游戏开启“减少动态效果”时直接切换形状。忙碌状态的旋转同样遵循减少动态设置。

普通按钮使用铜质明暗渐变、内缘高光及凹压反馈；职业、祝福和投票卡片将SVG置于固定位置，避免挤压文字或改变卡片布局。原有稳定滚动槽与可用视口策略继续生效。

主要正文与炭黑底的对比度超过7:1；主按钮最暗铜色与深色文字约5.98:1，次级文字与较亮面板约5.43:1。实际浏览器检查字体加载、SVG变形、键盘聚焦、减少动态设置和移动布局，记录见[视觉验收](verification/bronze-design.json)。
