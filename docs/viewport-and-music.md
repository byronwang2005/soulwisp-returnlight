# 视口与场景音乐

页面外框固定适应动态视口，页头和页脚独立占位，中间区域使用剩余高度。欢迎页的三维背景、营地预览和远征画布跟随所在区域缩放；文档本身不产生横向或纵向滚动。

长内容的滚动归属保持一致：营地仅滚动工坊内容，远征大厅和职业席位各在自己的面板内滚动，聊天、证据、训练指引与阶段弹窗各有明确边界。所有滚动区使用相同细轨道、颜色和预留槽。需要隐藏滚动条时只把滑块变透明，保留轨道宽度，按钮与文字位置不变；不使用`display:none`或`scrollbar-width:none`移除滚动条。预留槽遵循[scrollbar-gutter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-gutter)。

手机采用紧凑页头、上下分区和可收起的远征手册。横屏矮窗口把教程指引与阶段弹窗并排；竖屏将弹窗放在指引下方。过长内容在所属面板内滚动，交互按钮可以通过组件滚动到达。

播放器复用[Howler](https://github.com/goldfire/howler.js)。用户第一次点击或按键后启用音乐，遵循浏览器[音频启动规则](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)。只加载当前场景；切换使用900毫秒淡出／淡入，切换结束释放旧曲目，快速跳转不堆积播放实例。公共语音连接期间及议会阶段降至音乐设定音量的18%，离开语音后恢复。标签页隐藏、总静音、音乐关闭或音乐音量归零时暂停。

音乐与音效分别调节音量；首页音符和远征齿轮共用同一份设置。旧账号的反馈设置自动补齐音乐默认值。设置保存于本机并在同源标签页同步，语音收听与麦克风独立控制。

编曲离线合成为MP3，运行时不创建持续振荡器合成背景乐。采购成本0元，时长、响度与文件校验见[音频清单](../apps/web/public/audio/manifest.json)；资产与软件许可见[许可说明](asset-licenses.md)。验收覆盖真实浏览器解码与播放、音量保存、语音降音量、滚动槽稳定性、训练面板避让及四人动态阶段布局。
