# 暮钟城与第一缕亡絮

英文名称 **Soulwisp: Returnlight**。亡絮的英文专名为 **Soulwisp**，复数 **Soulwisps**；指亡者记忆凝成的银白絮丝。归灯芯为 **Returnlight Core**，归灯柱为 **Returnlight Beacon**。
四十年前，暮钟城发现死者记忆会化成银白纤维。人们称它为**亡絮**，将它织入灯芯：灯下可以重见故人的片段，城外的灰雾也随之退去。

城主希望灯永不熄灭，将活人的名字也写入织灯名册。守钟人艾琳在最后一场仪式中敲断钟绳，城没有燃尽，却被留在同一个终夜。灰月之下，失名的人影徘徊，记忆仍不断化作亡絮。

城外的余灯集市建立了归灯行会。每支远征队携带一盏归名灯进入旧城：采集散落亡絮、修复归灯柱，从守门者手中取回归灯芯，在终钟响起前将它护送出城。归名灯保存同行者的名字，因此成为回响的人也能随队伍结算回到集市。

守灯者希望让旧城的记忆得到安息。蚀月者认为释放全部记忆会熄灭城外赖以生存的灯，于是混入行会，暗中阻断远征。他们与同伴拥有相同职业，能够真心救人、修灯和交易；这些行为不能证明最终立场。

归灯厅保护议会免受灰雾侵扰，却无法替人判断真相。同行者只能带着亲眼所见、工程记录与彼此的陈述作出裁决。封印使身体化为回响，不在当场宣布立场；终钟才揭开这一夜的选择。

故事不限定队伍人数、狼人数或章节数量。4–10人使用同一世界背景，目标与规则由房间配置决定。

## 新手教程：第一缕亡絮

新人拾起第一缕亡絮，听见艾琳的残留记忆，随后亲手完成六段训练：移动采集、公共工程、战斗救援、证据议会、祝福选择、归灯芯净化与最后八秒护送。返回集市后认识外观、技能形态与营地制作。

可选蚀月练习补充腐化、共享蚀息与隐蔽行动。训练场使用独立物资；重玩不会产生对局材料。曾帮助修灯的同行者也可能选择腐化，用实际行为传达故事冲突。
