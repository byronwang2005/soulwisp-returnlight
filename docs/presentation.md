# 场景与界面

本文集中说明当前场景、输入、画质、界面和音乐约定。玩家操作见 [玩家手册](player-guide.md)，资源来源见 [资产许可](asset-licenses.md)。

## 场景与尺度

KayKit 模型直接以 GLB 渲染；身体脚底到头顶约 2.2 渲染单位，装备不参与身体测量。罩帽斥候以同包 Rogue 身体作为参照。比例、动作与脚底偏移由 [资产清单](../apps/web/public/assets/manifest.json) 和 `scripts/scene-assets.mjs` 核验。

[共享场景配置](../packages/shared/src/scene.ts) 定义单位换算、人物半径、站点占地、道路半宽和材质世界尺度。站点为各章预留独立槽位并避开入口；布局、服务端通行、小地图和训练导航共用地图连接。

`ground-geometry.ts` 合并区域与道路，扣除重复覆盖；UV 使用世界坐标。区域与道路分别使用两种石材，提供 1K / 2K 颜色、OpenGL 法线与 ARM 贴图。重复静态箱体合批为 InstancedMesh，动态角色与守卫独立渲染。外围石岸、苔藓和残墙避开通行范围。

## 输入、动作与镜头

服务端维护朝向及 `SelfView.actions`，提供动作目标、距离、可执行状态和阻止原因。客户端按距离、朝向与稳定 ID 选择目标；新目标至少近 10 个规则单位才切换，读条固定目标，完成时由服务端再次校验。

攻击从前方 120 度寻找守卫，再找显形角色与普通玩家；救援、护盾和工程分别寻找适用目标。交接需要双方确认。隐藏玩家不发送坐标或朝向。

WASD、方向键和触屏按镜头方向移动；道路导向在横向转向时释放。五瓣心灯每瓣表示 20 点生命，低生命闪动，倒地提示救援。

`render-motion.ts` 以 80 ms 缓冲插值授权位置，不向最新坐标外推；传送清空缓冲。镜头位置与注视点使用同一渲染位置，受击抖动不累积偏移。命中、格挡、拾取和工程完成依据服务端反馈播放；减少动态效果保留危险与命中提示。

## 训练与画质

六课训练复用 `GameEngine`、地图和正式动作候选。除议会回堂外，换课保留当前位置；进度以完成动作和实际状态判断。续学重建已完成课所需状态，当前课重新完成；训练库存独立，完成奖励一次性发放。

`render-quality.ts` 提供自动、高画质、均衡、流畅。自动模式从最高档开始，连续两个 2.5 秒窗口低于 57 FPS 降档；达到 59 FPS 持续十秒后试升，失败后等待三十秒。五档逐步调整阴影、装饰、贴图、DPR 和法线；DPR 最高为 2。加载预热三秒，隐藏页面暂停渲染，恢复时重置采样。

帧率可跟随显示器或限制为 60 / 120 FPS，配置见 `preferences.ts`；服务端模拟频率独立于渲染。

## 视觉与布局

| 用途 | 色值 |
| --- | --- |
| 底色 / 面板 | `#171512` / `#25251e` |
| 古铜边框 / 选中 | `#b58a58` / `#dfbc87` |
| 正文 / 次级文字 | `#efe4ce` / `#aaa794` |
| 正向 / 危险 | `#9ab7a5` / `#e6978e` |

标题与故事使用 Source Serif 4 / Noto Serif SC，操作与数字使用 Source Sans 3 / Noto Sans SC；Fontsource 自托管字体。主题入口为 `bronze-theme.css`。

按钮在 `button-icons.ts` 明确配置图标，不从文案推断。选中只改变样式；开关、展开、请求中与完成图形对应实际状态。导航使用 `aria-current`，选择使用 `aria-pressed`，装饰 SVG 对读屏隐藏；减少动态设置关闭位移和变形动画。

外框适应动态视口；工坊、席位、聊天、证据和弹窗各自滚动。滚动区保留固定槽，隐藏滑块时不移除轨道。手机采用紧凑页头和可收起手册；矮横屏训练与弹窗并排，竖屏上下排列。相关入口为 `useViewport.ts`、`viewport.css` 和 `scene-ui.css`。

## 场景音乐

19 首原创立体声 MP3 随包发布，覆盖首页、营地、工坊、登录、连接、房间、训练、各阶段与胜负；映射见 `music-catalog.ts`，标题、时长与哈希见 [音频清单](../apps/web/public/audio/manifest.json)。

`music.ts` 使用 Howler，首次点击或按键启用，仅加载当前场景。切换以 900 ms 淡入淡出并释放旧曲目；公共语音连接和议会期间降至设置音量的 18%。隐藏页面、总静音、关闭音乐或音量归零时暂停。音乐、音效、语音收听和麦克风分别控制，浏览器偏好同源同步。

静态验证命令集中在 [本地开发](local-development.md)。历史渲染、布局与音乐记录见 [验收索引](verification/README.md)。
