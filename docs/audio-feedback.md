# 大厅提示与脚步音频

## 大厅与音量

大厅进入、退出、开麦、闭麦分别使用 320 / 280 / 150 / 130 ms 的短提示：上行钟铃、下行双音、明亮轻点击和低点击。自己与其他成员的真实状态变化都会提示；远端提示降低 3 dB，同类远端事件在 200 ms 内合并。

首次成员列表与重连同步静默，取消加入、连接失败和麦克风权限失败不产生成功提示。重复退出或导航清理只提示一次。关闭大厅收听时不播放其他成员提示，自己的操作仍有确认音。提示由音效滑杆控制。

`audio-mix.ts` 统一音乐增益 0.20、音效增益 0.65，不修改已保存的滑杆值。语音和议会期间音乐在此基准上再乘 0.18。总静音、音乐开关、隐藏页暂停和输出设备选择继续生效。

[素材清单](../apps/web/public/audio/sfx/manifest.json)保存来源、固定归档 SHA256、处理方法、文件校验和、时长、峰值、有效段 RMS 与 19 首背景音乐解码 RMS。短音有效段以幅度超过峰值 1% 的首尾界定；音乐使用完整解码立体声 RMS。音乐与音效均为 50 时，最小参考差为本人正常脚步 9.4 dB、大厅提示 14.7 dB，不包含 HRTF、远距离、遮挡或速度档的额外衰减。

## 试听与素材生成

- [四种大厅提示＋音乐 50](../apps/web/public/audio/sfx/preview-lobby-50.wav)：第 1–4 秒依次进入、退出、开麦、闭麦。
- [两种地面＋速度变化＋音乐 50](../apps/web/public/audio/sfx/preview-footsteps-50.wav)：石板从第 1 秒、鹅卵石从第 6 秒开始，依次慢速、正常、加速，各三步。
- [方向、远近与遮挡＋音乐 50](../apps/web/public/audio/sfx/preview-direction-50.wav)：第 1–5 秒依次左近、右近、左中、右远、左侧遮挡。

试听采用立体声左右定位；游戏内前后定位由浏览器 HRTF 生成。参考 RMS 是离线电平指标，实际听感需在耳机或音响上试听。

脚步复用 Kenney Impact Sounds 1.0 的五个硬地样本，鹅卵石叠加 TinyWorlds / pdsounds.org 的碎石录音，均为 CC0。四种大厅提示为原创离线合成。单声道 24 kHz WAV 随包发布，运行时不访问素材提供方。播放沿用现有 Howler 与原生 Web Audio，没有新增 npm 依赖。

重新生成需 Python、numpy、ffmpeg：

```sh
python3 scripts/generate-sounds.py --download
# 已有 .local/audio-sources 缓存时不再联网：
python3 scripts/generate-sounds.py
```

生成器验证源归档哈希，去直流、裁静音、淡入淡出、均衡并校准有效段 RMS，峰值限制为 0.85。许可随运行资产保存。

## 服务器脚步与听声辨位

探索与撤离期间，服务器以碰撞处理后的实际行走距离累计步幅，每 36 游戏单位一步；正常速度间隔约 343 ms。携芯减速、轻絮加速和小幅方向输入自然改变节奏。闪避、推挤、传送与复活不累计行走距离；闲置超过 500 ms 或非行走位移后重新累计。

房间范围优先判为石板，其他可走道路为鹅卵石。正常速度石板听距 14 米、鹅卵石 16 米。低于基础速度 95% 时听距乘 0.85、音量减 2 dB；高于 105% 时听距乘 1.10、音量加 1.5 dB。近、中、远分界为听距的 30% / 65%，增益为 1 / 0.45 / 0.15。

地图不连通区域间不传声。连线每 0.25 米检查可走地面，经过空隙时听距乘 0.55、音量减 6 dB，并使用 1.4 kHz 低通。视觉灰雾不阻断声音。此模型基于地面连通区域，场景装饰和工程物件未建模为声学墙体。

`SelfView.footsteps` 使用接收者独立序号，包含时间、材质、速度档与本人标记；远端事件只有 16 方位扇区、三个距离档和遮挡标记，不含身份与世界坐标。隐藏角色位置仍为 `null`。倒地玩家保留听觉，封印和断线玩家不接收新脚步。

以固定镜头的屏幕上方为前方，远端使用 HRTF；距离与遮挡衰减只计算一次。本人声音居中且减 3 dB。每种材质有五个变体，避免连续重复，音高随机变化不超过 ±3%。最多同时播放 16 个脚步，优先保留本人和近处声音；大厅提示不占此名额。

服务器队列最多保留 64 条、最近 500 ms 的事件。客户端去重并丢弃首次同步、重连、阶段切换和前台恢复的积压，退出阶段或页面时停止脚步。训练复用相同引擎和播放路径，不显示声源标记。

## 静态验证

Node.js 24 下执行：

```sh
npm run check
npm run build
npm exec vitest run tests/footsteps.test.ts tests/lobby-sounds.test.ts tests/sound-player.test.ts tests/sound-assets.test.ts tests/music.test.ts tests/rules.test.ts tests/scene-interaction.test.ts
```

音频图使用模拟节点验证 HRTF 参数、滤波、并发优先级、设备路由调用、音量更新与释放；大厅测试模拟 SDK，不启动媒体服务。素材检查读取 PCM、哈希与混音参考数值。浏览器、真实多人、设备试听和 HRTF 听感不包含在这些静态检查中。
