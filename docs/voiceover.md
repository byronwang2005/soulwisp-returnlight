## 男声如何演绎

| 用途 | 录音时怎么读 | 后期方向 |
| --- | --- | --- |
| 艾琳／引路人 | 自然男声，放松、温和，像对一个人说话 | 清理底噪、柔和均衡、轻量音色塑形；故事可有很短的空间尾音 |
| 阶段报幕 | 中低声区，发音稳，句尾明确 | 适当增加厚度、压缩动态；行动提示保持干净 |
| 操作提示 | 直接、清楚，稍比故事快 | 尽量保留原声，轻压缩、少混响 |

不用改变角色名称，也不用夹嗓子、耳语或刻意压低声音。先把“温暖”和“庄重”录出来；录制时的情绪会影响最终效果。

如果希望艾琳最终呈现明确女声，后续需要另选声音转换模型与可用的目标音色。均衡与小幅音高调整能改变厚薄、明暗，不能可靠地把男声变成自然女声。这次先准备干净原声，模型选择和转换效果用试音确认。

## 怎么录、怎么发

1. 在安静、软装较多的房间录制；关掉背景音乐。保持同一设备、位置和距离，嘴离麦克风约 15–20 厘米，稍微偏离正前方，减少喷麦。
2. 能设置时选单声道 WAV、48 kHz、24 bit。手机录音的 M4A 也可以直接发；保留原文件，不必先转码。
3. 不添加混响、变声、背景音乐或强降噪。不贴着麦克风，不让大声句子出现明显破音。
4. 按正文自然朗读；数字已尽量写成中文。每条之间停两秒。读错时停两秒，从本条开头重读即可，不需要重录整批。
5. 分文件时用 `编号_take01.wav`，例如 `erin-lesson-01_take01.wav`；多版本用 `take02`。连续录音可命名 `P0_erin_take01.m4a` 或 `P0_herald_take01.m4a`，保持清单顺序，并说明是否跳过条目。
6. 可分批发。收到后按编号整理原声、切条、处理并导出游戏素材。

读音：亡絮 **wáng xù**，蚀月 **shí yuè**，蚀息 **shí xī**，艾琳 **ài lín**，阿芙 **ā fú**，珍藏 **zhēn cáng**，灯芯 **dēng xīn**。

## 收到音频后的处理与接入

先保留原声，再校正文案与漏录、切分条目，做轻量降噪、均衡、音色处理和响度统一。三条试音输出原声与处理版，听过后将选定风格用于同类条目。处理后的母版保留 WAV，发布素材按兼容性导出 MP3；实际时长、响度与文件校验值在导出后记录。

现有工程已用 Howler 播放音乐、原生 Web Audio 播放音效，并支持输出设备选择。后续配音复用这些机制，增加独立配音音量、开关、重听和字幕，不与麦克风聊天共用音量。配音播放时压低背景音乐，并在结束、打断、退出或失败时恢复。

接入规则：

- 所有配音都是本机播放；索引中的 `public` 表示内容公开，仍只根据本机收到的授权视图触发，不把配音发送到语音大厅或议会麦克风。
- 同时只播一条。终局和最后八秒优先；切课、切阶段、退出和隐藏页面清理旧条目，恢复前台或重连不补播过期提醒。
- 艾琳故事不与操作提示叠读。议会阶段提示保持简短，轮到玩家发言时让出声音；规则、背景和祝福说明优先手动点播。
- 秘密阵营朗读默认关闭，仅在玩家主动选择耳机私密点播时播放；不朗读狼同伴姓名、私密证据或预算。耳机仍需由玩家确认，浏览器无法证明声音不会外放。
- 事件成功提示只跟随授权状态变化、本人反馈或已经交付的公开记录。首次状态同步不作为新事件，不能用配音揭示未交付的行动或位置。
- 获胜配音等待实际 `result.winner`；等待结算时不播胜负。教程只在完成并保存成功后播完成语。
- 开麦、闭麦、脚步、挥剑等高频动作沿用短音效。登录表单、按钮标签、网络诊断和玩家自由输入保留文字。

## 工具与当前状态

本机已有 FFmpeg 和 ffprobe。可复用 [FFmpeg 的音频滤镜](https://ffmpeg.org/ffmpeg-filters.html)处理降噪、均衡和响度。[Rubber Band 音高与节奏处理](https://ffmpeg.org/ffmpeg-filters.html#rubberband)提供独立调节音高、节奏和音高变化时保留共振峰的选项；当前本机 FFmpeg 查询返回 `Unknown filter 'rubberband'`，尚不能使用这一滤镜。

[Rubber Band 官方仓库](https://github.com/breakfastquay/rubberband)提供源代码、构建说明与 GPL-2.0-or-later／商业授权说明。当前仅作为离线处理候选，没有向项目加入库、模型或 npm 依赖；后续若打包工具或模型，按其具体许可核对。
