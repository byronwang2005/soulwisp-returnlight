# 开发状态

按 2026-10-11 的仓库代码整理。应用包版本为 `0.1.0`，运行规则版本为 `wangxu-0.2.0`；两者分别维护。

## 实现范围

| 范围 | 代码入口与能力 |
| --- | --- |
| 账户与营地 | `apps/server/src/accounts.ts`、`db/`：登录、资料、材料、制作、研究、外观、最多五套配装预设与教程进度 |
| 4–10 人远征 | `packages/rules`、`apps/server/src/rooms.ts`：职业与秘密阵营、探索、战斗救援、工程、证据、议会、投票、祝福、护送和事务结算 |
| 训练与场景 | `training.ts`、`Tutorial.tsx`、`World.tsx`：六课训练、蚀月练习、保存续学、三维模型、连续铺装、动作与反馈 |
| 设置与音频 | `SettingsDialog.tsx`、`music.ts`：用户资料、画质与帧率、音频设备、音乐、音效与交互反馈 |
| 语音 | `voice.ts`、`voice-lobby.ts`：议会发言权限及独立首页公共大厅 |
| 运维 | `scripts/`、`deploy/`：本地启动、备份与空库恢复、源码打包、VPS 模板和 CI 成功后的自动发布 |

使用流程见 [玩家手册](player-guide.md)，运行边界见 [架构](architecture.md)。

## 验收记录

历史记录包含本地规则与集成测试、浏览器教程、4–10 人公网对局、语音、渲染采样、数据迁移和备份恢复，统一从 [验收索引](verification/README.md) 查阅。这些旧记录不能说明当前 `wangxu-0.2.0` 工作区已经发布或验收。

每次修改默认执行 Node.js 24 类型检查、生产构建及相关源码 / 资产检查。实时集成、浏览器和设备 / GPU 测试仅在用户明确要求时执行，命令见 [本地开发](local-development.md)。

## 待验收事项

- 各人数档真人轮换职业与阵营，记录胜率、证据使用、回响参与、等待时间和自愿再玩，校准社会推理体验。
- 多设备完整训练 → 对局 → 制作 → 换装 → 下一局，覆盖十人战斗、语音、重连与结算。
- 桌面与手机持续帧率、触摸操作、耗电、碰撞和物理震动体验。
- 英国 / 欧洲实际 Wi-Fi 与移动网络的麦克风、互听和端到端延迟；测试条件见 [语音大厅](voice-lobby.md)。
