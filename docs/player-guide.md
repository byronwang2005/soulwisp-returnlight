# 亡絮：归灯 · 玩家手册

## 第一次进入

打开[在线游戏](https://gaming.byron.wang/)，点“踏入余灯集市”，填写昵称、邮箱和密码创建账户。账户会保存材料、收藏、外观和配装。点“开始归灯训练”，跟随艾琳留下的记忆完成六段操作；也可以先体验访客训练，再注册。

![公网余灯集市入口](screenshots/public-welcome.png)

训练可保存离开、继续和重温。采集、工程、战斗、讨论、祝福和护送使用正式规则的交互方式；训练物资独立，重复训练不增加对局材料。

## 和朋友开一局

在营地点“开启归灯远征”，选择人数并创建房间。把六位邀请码交给朋友；其他人在远征大厅输入邀请码加入。每人使用独立账户，选择公开职业和技能形态，全部准备后自动出征。推荐首局四人。

![四人远征](screenshots/four-player-desktop.png)

秘密阵营在探索开始时分配。相同职业既可能是守灯者，也可能是蚀月者；修灯、救援和交易都不能直接证明阵营。

## 探索和交互

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动 | WASD / 方向键 | 右下方向控制 |
| 选择目标 | 点击地标、角色或目标列表 | 点击目标列表 |
| 采集、工程、救援 | E / 交互按钮 | 交互按钮 |
| 攻击 / 推挤 | 空格 | 攻击按钮 |
| 职业技能 | Q | 技能按钮 |
| 闪避 | Shift | 闪避按钮 |

靠近目标再交互，读条期间保持位置；移动或受干扰会中断。将采集的亡絮交到收絮匣，可以帮助全队建设归灯柱。章末未消耗的已释放工程亡絮统一进入公共仓库。

守灯者有两条胜利路线：通过证据表决封印全部蚀月者，或者完成归灯工程、击败精英、净化唯一归灯芯并护送撤离。最后八秒需持续满足守圈条件。胜负在固定终局判定；被封印后仍可通过回响文字、有限遗票和引路参与。

背包空间有限。旧城珍藏可以丢弃或提出交接，对方接受后才转移。携带归灯芯会占两格；选择他人后，可在背包中提出交接。

## 议会、证据和表决

探索时查阅自己的亲历记录；进入议会后打开“证据”，选择记录发布到证据板。议会先逐席陈述，再自由讨论；点“连接议会语音”并授权麦克风，到自己的发言轮再开启麦克风。语音不可用时直接使用文字。

投票需要严格超过有权者的一半，弃权计入分母，提交后不可改票。首章只产生有限监视；后续封印额度按人数配置。不要只追逐嫌疑，归灯工程也需要人手。

## 调整反馈和画质

导航栏的音符按钮和远征右上齿轮均可调整背景音乐、音效音量、设备震动和动态效果，设置会保存。首次点击或按键后启用配乐；集市、制作、研究、训练各课及远征各阶段拥有不同BGM，切换时淡入淡出。公共语音及议会期间音乐会自动降低音量，切到其他标签页后暂停。挥击有即时破风声；命中、格挡、受伤、碰撞、拾取和工程完成使用服务端确认反馈。支持震动的手机浏览器会输出不同触感节奏。

页面固定适应窗口大小。营地工坊、席位列表、聊天、证据和弹窗内容过长时，在组件内滚动；页头和游戏操作不会随整页滚走。组件滚动条预留固定宽度，出现或隐藏不挤动文字和按钮。

点顶部“高画质 / 流畅”切换画质。减少动态效果保留危险提示与命中信息。

## 结算后制作与换装

返回营地，打开“灯屑制作”，用有效对局奖励制作装饰、职业礼装或摆件。打开“秘闻研究”收藏研究蓝图及对应配色；标准对局的允许技能池对所有账户开放。

![制作与换装](screenshots/camp-crafted.png)

在“外观与配装”选择已收藏外观、职业与技能形态，点“穿戴并保存”。填写预设名称，点“保存账户预设”，以后可以再次加载。首局即可制作“第一缕·絮灯饰”；下一局入房时自动应用可用的职业与外观。

刷新后可以恢复短断线席位。连续断线恢复窗口为真实六十秒；超时对局无效，不产生新增奖励。
